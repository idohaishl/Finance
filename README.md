# תקציב הבית

דשבורד אינטראקטיבי לניהול תקציב משק הבית – קובץ HTML אחד (`index.html`), בעברית ובשקלים.

פותחים את `index.html` בדפדפן (נדרש חיבור לאינטרנט לטעינת הגופנים, הגרפים וספריות הייצוא).

- מסך פתיחה: רווק/ה, זוג או משפחה עם ילדים – הקטגוריות מותאמות אוטומטית, ואפשר למלא נתוני דוגמה ל-6 חודשים.
- סיכום חודשי, גרפים, טיפים, קוביות לכל קבוצה, טבלאות עריכה והיסטוריה של 6 חודשים.
- הנתונים נשמרים אוטומטית בדפדפן (localStorage). גיבוי/שחזור לקובץ JSON דרך ⚙️ הגדרות.
- ייצוא לאקסל (עם נוסחאות) ולדוח PDF.
